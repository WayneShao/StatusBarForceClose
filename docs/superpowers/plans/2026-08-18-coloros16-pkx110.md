# ColorOS 16 And PKX110 Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add fail-closed ColorOS 16 status-bar event support to the existing multi-ROM StatusBarForceClose APK without regressing HyperOS 4.

**Architecture:** A pure strategy selector chooses the existing Xiaomi dispatch hook or a LuckyTool-inspired Oplus onFinishInflate listener based on verified class structure. Both event sources feed the existing detector and force-stop pipeline; SDK packaging expands only from minimum 37 to minimum 36.

**Tech Stack:** Java 17, Android SDK 37 with minSdk 36, libxposed API 102, JUnit 4, Gradle Android plugin, GitHub Actions, ADB.
